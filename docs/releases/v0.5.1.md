# Gonimbus v0.5.1 Release Notes

**Release Date**: 2026-11-20
**Status**: Opt-in `--require-source-match` source-read binding and input `source_version_id` native version pinning for `transfer reflow`, additive `provider.RevisionHeader` (`HeadRevision`), Go `1.26.11` security and dependency updates, and retirement of opt-in `-tags gonimbus_libsql`

## Summary

v0.5.1 adds opt-in strict source-read binding (`--require-source-match`) and
input-side native version pinning (`source_version_id`) for `transfer reflow`
across both the `pkg/reflow` library engine and the CLI worker pool so copied
bytes are bound to the admitted source revision before any destination write;
adds the optional `provider.RevisionHeader` (`HeadRevision`) interface on S3
and GCS providers so version-pinned metadata and timestamp lookups never fall
back to unversioned `Head`; updates the Go toolchain pin to `go1.26.11`
(`GO-2026-6859`) alongside cooled Go module refreshes; and retires the opt-in
`-tags gonimbus_libsql` build tag and `github.com/tursodatabase/go-libsql`
dependency.

## Highlights

### Source-read binding (`--require-source-match`) and native `source_version_id` pinning

- **Opt-in strict source-read binding (`--require-source-match`):** Pass
  `--require-source-match` on `gonimbus transfer reflow` (or set
  `Config.RequireSourceMatch: true` in `pkg/reflow`) to enforce pinned source
  reads via `provider.RevisionGetter` (`GetObjectRevision`) across copy,
  conditional copy, quarantine copy, and collision duplicate body comparisons.
  - **Preflight refusal (`replay_unverifiable`, exit code `40`):** Sources
    without `provider.RevisionGetter` fail closed at preflight before any
    destination probing (with a bounded 1 MiB stdin sniff).
  - **Per-provider enforcement:** S3 sends RFC 9110-quoted `If-Match` on
    `GetObject` and never retries `412 PreconditionFailed` as an unconditional
    read; GCS binds reads to the matched object generation, rejects
    transparently decompressed responses, and verifies stream length and
    Castagnoli CRC32C (including valid zero checksums and SDK CRC read errors);
    `file://` enforces the configured symlink policy (refusing symlinks under
    the default `skip` policy) and verifies the open descriptor's `fstat`
    size+mtime revision token.
  - **Clear failure taxonomy:** Missing expected tokens fail with
    `reason: "source_token_missing"`, changed objects fail with
    `reason: "source_changed"` (never misclassified as destination collisions),
    and deleted objects report `reason: "not_found"`.
- **Native input version pinning (`source_version_id`):** Input records on
  `gonimbus.reflow.input.v1` may supply an optional `source_version_id`
  (`minLength: 1`, `pattern: "\\S"`, carrying an S3 `VersionId` or GCS
  generation number). Whenever `source_version_id` is present on an input
  record, Gonimbus honors it via `RevisionNative` reads — allowing historical
  object versions to be copied even after the key has been overwritten or behind
  an S3 delete marker.
  - **Dual-token verification:** When both `source_version_id` and
    `source_etag` are supplied, the observed ETag of the pinned version is
    verified against `source_etag` before writing any destination bytes; a
    mismatch fails closed with `reason: "source_changed"`.
  - **Revision-pinned metadata and collision checks (`HeadRevision`):** When
    `--metadata-policy=preserve` or `--on-collision=overwrite-if-source-newer`
    requires source metadata or timestamps on a version-pinned item, Gonimbus
    resolves them strictly against the pinned revision via
    `provider.RevisionHeader.HeadRevision` instead of unversioned `Head`. CLI
    tasks also track `SourceSizeKnown` so equal-timestamp tie-breakers refuse
    unknown source size (`collision.source_size_unavailable`) with full parity
    with `pkg/reflow`.
  - **Fail-closed validation:** Blank/whitespace values, JSON `null`, the S3
    `"null"` sentinel version ID, non-positive GCS generations, and non-versioned
    providers (`file://`) fail closed with `reason: "replay_unverifiable"`.
- **Compatibility guard against older binaries:** If you rely on source binding,
  including `source_version_id`, pass `--require-source-match`. gonimbus 0.5.0
  and earlier reject the flag, so the run fails closed. Without the flag, 0.5.0
  ignores `source_version_id` and copies the current object.
- **Read-bound terminal receipts:** Pinned `complete` and `quarantined` records
  stamp the read-bound `source_etag`, optional `source_version_id`, and
  `source_match` (`expected_etag`, `expected_version_id`, `observed_etag`,
  `observed_version_id`), with linear-time receipt-handle sanitization across
  JSONL records, SQLite checkpoints, collision observations, and provenance
  sidecars. Default unpinned runs preserve byte-identical `v0.5.0` output.

See
[Source-Read Binding (`--require-source-match`)](https://github.com/3leaps/gonimbus/blob/v0.5.1/docs/user-guide/transfer.md#source-read-binding---require-source-match)
for the complete operator guide and schema examples.

### Go `1.26.11` toolchain (`GO-2026-6859`) and dependency refresh

- Updates the Go toolchain pin to `go1.26.11` (keeping the `go 1.26.0` module
  directive) across `go.mod`, CI/security/release workflows, release workflow
  pin checks, and source-install documentation to address `GO-2026-6859`.
- Refreshes cooled Go module dependencies including `aws-sdk-go-v2`
  (`v1.48.0`, `service/s3 v1.114.10`, `smithy-go v1.28.9`),
  `cloud.google.com/go/storage v1.70.0`, `google.golang.org/api v0.313.0`,
  `modernc.org/libc v1.81.0`, `modernc.org/sqlite v1.62.0`,
  `github.com/bmatcuk/doublestar/v4 v4.10.4`, `github.com/go-chi/chi/v5 v5.5.0`,
  `github.com/spf13/pflag v1.1.0`, `golang.org/x/crypto v0.59.0`,
  `golang.org/x/oauth2 v0.38.0`, `golang.org/x/sync v0.25.0`,
  `golang.org/x/sys v0.50.0`, `golang.org/x/text v0.44.0`, and
  `google.golang.org/grpc v1.85.0`.
- Bumps CI `golangci-lint` to `v2.15.0`, aligns `.goneat/tools.yaml` to
  `goneat v0.6.8`, hardens `Makefile` `license-audit` ephemeral `sbom` cleanup
  against symlinks, and resolves local non-CI `decernor` via
  `GONIMBUS_DECERNOR_BIN`, `DECERNOR_BIN`, then `PATH` in
  `make release-anchors-check`.

### Retirement of opt-in `-tags gonimbus_libsql`

- Retires the opt-in `-tags gonimbus_libsql` build tag and removes the
  `github.com/tursodatabase/go-libsql` dependency because Go `1.26.11` rejects
  precompiled LTO bitcode sections in `#cgo LDFLAGS` static archives.
- All official and source builds continue using pure-Go `modernc.org/sqlite`
  for local SQLite index stores alongside default `durable-index/v0` durable
  indexes; remote `libsql://` and `https://` index URLs fail closed with
  `"remote libsql is not supported in this release"`.

## Library API

There are no breaking changes to the Stable embedded library API.

- **Additive (`pkg/provider`, `pkg/provider/s3`, `pkg/provider/gcs`):** Adds
  the optional `provider.RevisionHeader` interface
  (`HeadRevision(ctx, key, revision)`) implemented by `s3.Provider.HeadRevision`
  and `gcs.Provider.HeadRevision` for revision-pinned metadata lookups without
  falling back to unversioned `Head`.

## Release provenance

- Before importing a downloaded public key, establish the expected GPG signing
  key, exact signing subkey, and minisign public-key fingerprint through an
  independently trusted maintainer channel. Follow the complete
  [release-verification guide](https://github.com/3leaps/gonimbus/blob/v0.5.1/docs/security/README.md).
- The tagged public verification material is
  [the OpenPGP key](https://github.com/3leaps/gonimbus/blob/v0.5.1/docs/security/release-signing-keys.asc),
  [the minisign public key](https://github.com/3leaps/gonimbus/blob/v0.5.1/docs/security/gonimbus-minisign.pub),
  [the pinned signing subkey](https://github.com/3leaps/gonimbus/blob/v0.5.1/config/release/signing-subkey.txt),
  and [the expected fingerprint anchors](https://github.com/3leaps/gonimbus/blob/v0.5.1/keys/expected-fingerprints.txt),
  and both public keys and both fingerprint anchor files are attached to the
  GitHub release as assets.
- Release tags are GPG-signed. After validating the public material against
  the committed anchors, verify with `git tag -v v0.5.1`.
- Checksum manifests are signed with minisign and PGP; the published assets are
  byte-identical to the signed set, GitHub release immutability is verified at
  publication time (`make release-stage-published`), and Go proxy, Homebrew tap,
  and Scoop bucket parity are verified against the staged release (`make
release-verify-registries`).
- The tag workflow is read-only: it verifies the signed tag against the public
  pin committed in the tagged commit, builds, and hands the artifacts to the
  maintainer ceremony. It does not create the release.

## Install

```bash
brew install 3leaps/tap/gonimbus                      # macOS Apple Silicon, Linux (v0.5.1)
brew install 3leaps/tap/gonimbus@0.4                  # pinned terminal v0.4.7 minor line
sfetch --repo 3leaps/gonimbus --tag v0.5.1 --dest-dir ~/.local/bin
go install github.com/3leaps/gonimbus/cmd/gonimbus@v0.5.1
```

```powershell
scoop bucket add 3leaps https://github.com/3leaps/scoop-bucket
scoop install gonimbus                                # latest stable (v0.5.1)
scoop install gonimbus-0.4                            # pinned terminal v0.4.7 minor line
```

## Verification

- `gonimbus version --json --extended` reports `"version":"0.5.1"`.
- Passing `--require-source-match` on `gonimbus transfer reflow` fails closed on
  `v0.5.0` and earlier (`unknown flag: --require-source-match`) and enforces
  strict ETag and `source_version_id` source-read binding on `v0.5.1`.
- Existing `0.4.x` (`durable-v2`) and `0.5.0` (`durable-index/v0`) index
  artifacts remain readable as-is; local SQLite indexes continue using pure-Go
  `modernc.org/sqlite`.
